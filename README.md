# Garden Tracker

Group project developed at **Częstochowa University of Technology (Politechnika Częstochowska)**.

**Team members:** Oleksandr Kovalenko, Fabian Telęga, Yurii Levchuk.

Garden Tracker is a web application for managing plants, garden beds, and everyday gardening activities.

## Tech Stack

- React/TS
- Java

## UI

The interface is designed using the **shadcn/ui** component library and its corresponding Figma UI kit.
